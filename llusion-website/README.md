# LLusion website

A one-page link-in-bio site to replace Linktree.

- **To update links or the featured spot:** edit `links.js` (it has instructions inside).
- **Brand:** orchid pink `#E274D9`, black, white. Fonts are Fredoka and Inter.
- **To host it:** upload this whole folder to Netlify Drop, Vercel, or GitHub Pages.
